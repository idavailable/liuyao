## 〇、一句话定位

给「用神两现/多现的取舍」立一个**引擎级显式参数**（模式完全照抄夜子时开关
`LY.nightZiMode`：模块级全局 + 默认值 + 门派标注），把《增删卜易·两现章第三十二》
野鹤法「舍其不空而用旬空／用逢破之爻」作为**非默认口径**接入断语层。
**默认口径下的输出逐字节不变**；非默认口径只做**陈述层增量**（新增一条带门派标注的断语
与应期锚点线索），不改主用爻、不改 trend——「两派并置」而非「两派切换」。

## 二、问题 1：分歧有哪几派，古籍依据是什么

### 2.1 分歧实质：两现/多现遇「空破」时，以何者为应期之锚

用神两现且两爻一空一不空（或一破一不破）时，两派读法不同。
**两派在本仓语料内的证据如下，出处均可回溯：**

**乙派：《增删卜易·两现章第三十二》野鹤法——空破之爻为应期之锚。**
三例 conclusion 原文（`tests/guji/corpus/zengshan-boyi.json`）：

| 语料 id | 原文（逐字） | 盘面事实 |
|---|---|---|
| `zsby-01406`（未月庚子日占求财，风天小畜） | 「应临月建之财以克世，许之必得，彼问何时到手，余以次日辛丑冲动未财日得，**却得于辰土出空之日，此乃舍其不空而用旬空**。」（conclusion L8758） | 财两现：三爻辰（旬空）、四爻未（不空，临应临月建）。**吉断用未（旺者），应期用辰（空者）** |
| `zsby-01414`（未月甲午日占升迁，师之涣） | 「但卦中官星两现，一空一破，**至辰年官而出空一定高升**……十年两调一升，**皆应实空之年也**。」（conclusion L8903） | 官两现：二爻辰（旬空辰巳）、四爻丑（月破）。以空者辰「出空」为期（辰年填实） |
| `zsby-01422`（亥月丙午日母占子脱厄，雷地豫之归妹） | 「余见卦中三现子孙，俱生世爻，午逢日建而静，两爻巳火逢月破许巳年脱厄，乃实破之年也，果脱厄于巳年。**此乃卦中用神三现，而用逢破之爻也**。」（conclusion L9048） | 子孙多现：四爻午（不空不破，临日建）、二爻巳（月破，发动）。以破者巳「实破」为期（巳年） |

关键观察（决定 §三的建模）：**野鹤在 01406 的吉断本身仍用旺者**（「应临月建之财以克世，
许之必得」），空者辰土承担的是**应期锚点**——「舍其不空而用旬空」说的是应期落在谁身上，
不是把吉断改挂在空者上。01414／01422 亦同构：断语重心在「出空／实破之期」。

**甲派：通行次序取舍（本仓现行实现）——空破不参与取舍维度。**
次序链「发动者→临世应者→旺者→在前之爻」标注于 `analyze.js:82`（「古法次序」），
由 `test-rules.js` §11·六 锁定。其**整链的古籍明文出处：待核实**——本仓《卜筮正宗》语料
为表格式装卦数据（只覆盖纳甲/六亲/六神/伏神，不含论说章文本），引不到整链条文，不编造。
「旺者」维度有原文侧证：`zsby-0542` 原文「**辰土父母临月建，即用辰土为用神**」
（三爻辰、上爻戌两现，取临月建者；见 `tests/guji/cases/zengshan-boyi.json`
`zsby-0542-liuchong` 的 quote/note）。

### 2.2 两法在语料内的同归率（扫描实测，方法同 README §七影响面实测）

对《增删卜易》207 例语料 × 5 用神（妻财/官鬼/父母/子孙/兄弟；`shi` 无两现）全量扫描：
**370 个 (卦例, 用神) 组合存在两现/多现**。其中按野鹤法规则（见 §3.3）计算应期锚点：

- 锚点爻与现行主用爻**同爻**：315 个（两法同归，不产生分歧输出）
- 锚点爻与现行主用爻**不同爻**：55 个（真分歧场景，参数化才产生增量）
- 两现章 4 例语料的归属：01414（现行「在前之爻」恰取空者辰，同归）、
  01422（现行「发动者」恰取破者巳，同归）、01406（现行取未，野鹤锚点辰，**分歧**）、
  01458（官鬼单现，不适用）

> 《卜筮正宗》表格语料 197 例不参与本扫描：多数未印日支（无法判旬空/月破），
> 且该语料只对账装卦/六神/伏神，不驱动断卦链——参数化对它**结构性零影响**。

## 三、问题 2：参数如何设计（照抄夜子时开关模式）

### 3.1 参数与取值

```js
// public/core/analyze.js 模块头（与 calendar.js:19 同款）
LY.ysDupMode = 'priority'; // 'priority'（默认，通行次序取舍）| 'kongpo'（增删卜易·两现章野鹤法）
```

- **默认 `'priority'`**：行为与现状**逐字节一致**（守卫分支不触发）。
- **`'kongpo'`**：仅新增一条**陈述层断语**（tag `'两现'`）与一条应期锚点线索；
  `pickYongshen()` 本体**一行不改**——主用爻、trend、既有任何断语均不变。
- 全局开关而非函数入参，镜像 `LY.nightZiMode`（`calendar.js:19/156`）；测试用例
  设值→断言→`finally` 还原，与 `test-rules.js:225-238` 夜子时组同款。

**为什么是「陈述层并置」而不是「主用爻切换」**（本方案最关键的设计取舍，审核重点）：

| | 甲案：主用爻切换 | **乙案（推荐）：陈述层并置** |
|---|---|---|
| 语义 | kongpo 下 `pickYongshen` 直接改取空破者 | 主用爻仍按次序链；空破者作为**应期锚点**另立断语 |
| 语料忠实度 | 与 01406 野鹤自用法**相悖**（他吉断用未财旺者） | 逐例吻合：吉断用旺者＋应期用空破者（§2.1 三例全部对上） |
| trend 影响 | 55 个换爻组合中 **13 个 trend 迁移**（平→凶 11、平→吉 2，扫描实测） | **零迁移**（新断语不入 `aggregateTrend` 白名单，同卦型/刑害先例） |
| golden 冲击 | 68 条断语用例中 4 条换锚（3 条断言必红，见 §4.2），须每派各写一套期望并双跑 | **零冲击**：新断语是纯加法，既有断言按成员匹配不受影响 |
| 「同盘同解」承诺 | 默认口径仍同解，但 kongpo 口径同一盘有两个 trend 源 | 两口径输出可并排比对，同解性完整保留 |

甲案不是被否决的死案——若审核者认定「参数化就该换主用爻」，其代价已在 §四量化
（55 换爻 / 13 trend 迁移 / 3 条断语用例需按 §四 表格重写期望并双跑）。**本方案推荐乙案**。

### 3.2 门派标注格式（与夜子时开关现有标注一致）

夜子时的标注由三件套构成：README 口径声明行（`README.md:28`）、代码注释（`calendar.js:7-10`）、
输出携带模式字段（`calendar.js:183` `nightZiMode`）。新参数照抄三件套：

1. **README 声明行**（加在 `README.md:28` 夜子时行之后，同款句式）：

   > **取用神两现口径显式声明**：`LY.ysDupMode`（默认 `'priority'`：两现/多现按通行次序
   > 取舍——发动者→临世应者→旺者→在前之爻，空破不入取舍维度；`'kongpo'`：《增删卜易·
   > 两现章第三十二》野鹤法——两现遇空破「舍其不空而用旬空」「用逢破之爻」，以空破之爻
   > 为应期之锚；主用爻与吉断仍按次序链，两派并置陈述）

2. **断语文本与 basis 带门派名 + 出处 + 参数值**（kongpo 模式新增的唯一断语形态）：

   ```js
   {
     tag: '两现', rule: '用空破者应期',
     text: '用神妻财两现（三爻辰土值旬空、四爻未土不空）——《增删卜易·两现章第三十二》'
       + '「舍其不空而用旬空」（野鹤法）：以辰土出空之日为应期之锚；'
       + '主用爻仍取未土（通行次序，两派并置）。',
     basis: '《增删卜易·两现章第三十二》：「却得于辰土出空之日，此乃舍其不空而用旬空」；'
       + '同章「此乃卦中用神三现，而用逢破之爻也」——LY.ysDupMode="kongpo"（野鹤法）口径；'
       + '默认 LY.ysDupMode="priority" 为通行次序取舍，两派并置互不覆盖'
   }
   ```

3. **输出携带模式字段**：`out.yongshen.dupMode = LY.ysDupMode`（镜像 `pillars.nightZiMode`，
   消费侧可无条件读；默认值 `'priority'` 也照写，与 nightZiMode 常写 `'day'` 同款）。

### 3.3 kongpo 断语的触发条件（边界逐条显式）

对 `pick.all`（本卦同六亲现爻集合，长度 ≥ 2，且 `pick.source` 非 `'伏神'`）：

1. **空分歧优先**：集合中空者与不空者并存，且空者按**地支值**唯一 → 锚点为空者，
   断语「以 X 出空之日为应期之锚」（日级，线索入 `clues` 与 `layers.main`）。
2. **破分歧次之**：无空分歧（皆空或皆不空）而破者与不破者并存，且破者按地支值唯一 →
   锚点为破者，断语「以 X 实破（逢值）之期为应」（年/月级陈述；**不入日级应期窗口**，
   01414 辰年／01422 巳年超出窗口刻度，诚实陈述不硬算）。
3. 空者（或破者）地支不唯一、或两现但无空破分歧、或 `target === 'shi'`、或用神为伏神 →
   **不输出任何断语**（kongpo 模式静默回退，与默认口径完全一致——无分歧即无并置）。
4. 主用爻恰为锚点爻时（语料内 315/370 同归场景）**仍输出**：通行口径下该爻的空/破
   本就由 `ruleXunKong`/`ruleYuePo` 陈述，kongpo 断语补充的是「两现之中**为何以它为锚**」
   的门派读法（野鹤法明示取舍依据），语义不重复、来源可回溯。
